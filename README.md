# Сайт А.Л.О.Н.

Статический сайт для публикации книг. Каждая глава — обычная HTML-страница,
собранная заранее, поэтому её видят поисковики и читателю не приходится
скачивать весь роман, чтобы открыть одну главу.

## Что здесь лежит

Исходники — то, что правится руками:

```
build.py                   сборщик: делает все страницы сайта
src/site.css               стили
src/site.js                поле нитей, обложка, читалка
books/v-soznanie.json      текст первого романа по главам
books/v-soznanii.json      текст второго романа (пишется)
img/                       обложки и иконки
assets/fonts.css, fonts/   шрифты, лежат рядом с сайтом
```

Собранное — создаётся скриптом, править бессмысленно, перезапишется:

```
index.html                 главная: полка с обеими книгами и об авторе
kniga/index.html           «В сознание…»: аннотация, оглавление, благодарности
glava-1/ … glava-25/       главы первой книги
v-soznanii/index.html      «…В сознании»: оглавление
v-soznanii/glava-1/ …      главы второй книги
otzyvy/index.html          книга отзывов
404.html, sitemap.xml, robots.txt
assets/site.css, assets/site.js   копии из src/
```

Собранные файлы лежат в репозитории вместе с исходниками: GitHub Pages раздаёт
их как есть, без сборки на своей стороне.

## Как пересобрать

После любой правки в `src/` или `books/`:

```sh
python3 build.py
```

Проверить локально:

```sh
python3 -m http.server 8000
```

и открыть http://localhost:8000.

## Адрес сайта

Прописан одной строкой в начале `build.py`:

```python
SITE = "https://bengurionalon.github.io/alon_bg"
```

При переезде на свой домен поменять её и пересобрать: адрес подставляется
в canonical, в разметку для соцсетей и в `sitemap.xml`.

## Формат файла книги

```jsonc
{
  "title": "В сознание…",
  "author": "А.Л.О.Н.",
  "year": "2022",
  "place": "Южно-Сахалинск",
  "done": true,                    // false — книга ещё пишется
  "dedication": ["Посвящается моему отцу."],
  "annotation": ["Абзац аннотации.", "Ещё абзац."],
  "front": [ { "title": "Благодарности", "html": "<p>…</p>" } ],
  "chapters": [
    {
      "n": "1",                      // попадает в адрес: /glava-1/
      "html": "<p>Текст главы.</p>",
      "incipit": "Первые слова — для оглавления…",
      "chars": 36604                 // для оценки времени чтения
    }
  ]
}
```

Внутри `html` используются:

- `<p>` — обычный абзац;
- `<p class="scr">` — надпись на экране или терминале: моноширинный шрифт,
  по центру (в романе так идут сообщения бортового компьютера);
- `<hr class="brk">` — разрыв сцены внутри главы;
- `<em>` — курсив, `<b>` — полужирный.

## Как добавить главу в книгу, которая пишется

Дописанную главу дописать в `books/v-soznanii.json` — новым элементом в конце
`chapters`, с полями `n`, `html`, `incipit`, `chars` — и пересобрать. Страница
главы, оглавление, `sitemap.xml` и переходы «предыдущая/следующая» обновятся
сами; надпись «Продолжение пишется» сама переедет на новую последнюю главу.

Когда роман будет дописан, в его json поменять `done` на `true` и заполнить
`year` и `place` — тогда вместо «Продолжение пишется» встанет «Конец романа»
с местом и датой.

## Как добавить ещё книгу

В `build.py`, в списке `BOOKS`, добавить запись:

```python
{
    "file":  "tretya.json",            # файл в books/
    "page":  "tretya/",                # адрес страницы книги
    "ch":    "tretya/glava-{n}/",      # образец адреса главы
    "cover": "img/cover-tretya.jpg",
    "rkey":  "b3-",                    # приставка к ключу реакций
    "alt":   "описание обложки для незрячих",
}
```

`rkey` у уже выложенной книги менять нельзя: по ключу «`rkey` + номер главы»
хранятся отметки читателей под абзацами, и смена приставки их отвяжет.
У первой книги приставка пустая именно поэтому.

## Что сайт не делает

Ни аналитики, ни счётчиков, ни куки, ни внешних запросов — шрифты лежат
рядом с сайтом, а не загружаются с чужих серверов. Единственное, что
хранится у читателя, — размер шрифта и место, где он остановился; это
лежит в его браузере и никуда не передаётся.
