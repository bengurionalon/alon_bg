# Сайт А.Л.О.Н.

Статический сайт для публикации книг. Без сборки, без зависимостей, без сервера —
три файла, которые можно положить на любой хостинг.

```
index.html                 вся страница: вёрстка, стили, читалка, фон
books/v-soznanie.json      текст романа, разбитый на главы
img/cover-v-soznanie.jpg   обложка
```

## Как запустить локально

Просто открыть `index.html` двойным кликом не получится: страница подгружает
текст книги из `books/`, а браузер запрещает это для файлов с диска.
Нужен локальный сервер — одна команда в папке сайта:

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Как опубликовать

Подойдёт любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages,
Vercel или обычный хостинг с FTP. Собирать ничего не нужно — загружаются файлы как есть.

Для GitHub Pages: Settings → Pages → Source: `Deploy from a branch`,
ветка `main`, папка `/ (root)`.

## Устройство страницы

Это одностраничник: все три экрана живут в одном `index.html` и переключаются
по адресу в строке браузера.

| Адрес | Что показывает |
|---|---|
| `/` | главная: название, завязка, блок об авторе |
| `/#kniga` | страница книги: обложка, аннотация, оглавление |
| `/#glava-7` | читалка, глава 7 |

Позиция чтения хранится в браузере читателя (`localStorage`), на сервер ничего
не уходит. Статистики, комментариев и форм на сайте нет.

Фон — поле нитей на `<canvas>`, закреплённых по краям экрана. Они медленно
дрейфуют сами и расступаются вокруг курсора. В читалке фон выключается
полностью, чтобы не мешать тексту и не тратить батарею.

## Формат файла книги

```jsonc
{
  "slug": "v-soznanie",
  "title": "В сознание…",
  "author": "А.Л.О.Н.",
  "year": "2022",
  "annotation": ["Абзац аннотации.", "Ещё абзац."],
  "front": [
    { "title": "Благодарности", "html": "<p>…</p>" }
  ],
  "chapters": [
    {
      "n": "1",
      "html": "<p>Текст главы в абзацах.</p>",
      "incipit": "Первые слова главы — для оглавления…",
      "chars": 36604
    }
  ]
}
```

Внутри `html` используются три вещи:

- `<p>` — обычный абзац;
- `<p class="scr">` — надпись на экране или терминале, набирается моноширинным
  шрифтом по центру (в книге так оформлены сообщения бортового компьютера);
- `<hr class="brk">` — разрыв сцены внутри главы.

Курсив — `<em>`, полужирный — `<b>`.

## Как добавить книгу

1. Положить `books/<slug>.json` и обложку в `img/`.
2. В `index.html` найти `fetch("books/v-soznanie.json")` и указать нужный файл.

Сейчас страница рассчитана на одну книгу. Когда книг станет больше, понадобится
список на главной и выбор книги в адресе — это переделка на полчаса, но пока
она не нужна.

## Шрифты

Literata (текст), Unbounded (заголовки), JetBrains Mono (служебные надписи) —
подключаются с Google Fonts. Если сайт должен работать без обращений к Google,
шрифты нужно скачать и положить рядом, заменив `<link>` на локальный `@font-face`.
