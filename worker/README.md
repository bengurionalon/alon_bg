# Хранилище отзывов и реакций

Cloudflare Worker плюс база D1. Всё делается в браузере, ничего ставить
на компьютер не нужно. Бесплатного тарифа хватает с огромным запасом:
сто тысяч обращений в день.

## Что настроить (один раз)

### 1. База

Панель Cloudflare → слева **Storage & Databases** → **D1 SQL Database** →
**Create Database**. Имя: `alon`. Регион можно не трогать.

Откройте созданную базу → вкладка **Console** → вставьте целиком
содержимое `schema.sql` → **Execute**.

Во вкладке **Tables** должны появиться `reactions`, `reviews` и `rate`.

### 2. Worker

**Compute (Workers)** → **Workers & Pages** → **Create application** →
**Start with Hello World!** → **Get started**. Имя: `alon-api` → **Deploy**.

Откройте его → значок **Edit code** (`</>`) → удалите всё, что там есть →
вставьте целиком `worker.js` → **Deploy**.

### 3. Связать Worker с базой

В Worker'е → вкладка **Bindings** → **Add binding** → **D1 database**:

| Поле | Значение |
|---|---|
| Variable name | `DB` |
| D1 database | `alon` |

Имя переменной должно быть ровно `DB` — так к ней обращается код.

### 4. Секрет для отпечатков

Там же, в **Bindings** → **Add binding** → **Secret**:

| Поле | Значение |
|---|---|
| Variable name | `SALT` |
| Value | любая длинная случайная строка |

Нужен, чтобы отпечатки адресов нельзя было подобрать обратно.
Сами адреса нигде не хранятся.

### 5. Адрес

На странице Worker'а написан его адрес вида
`https://alon-api.ваш-логин.workers.dev`. Его нужно вписать в `build.py`:

```python
API = "https://alon-api.ваш-логин.workers.dev"
```

и пересобрать сайт: `python3 build.py`. Пустая строка возвращает
демонстрационный режим, где записи живут только в браузере читателя.

Если сайт переедет на свой домен, добавьте его в список `ALLOWED`
в начале `worker.js`, иначе браузер не пропустит запросы.

## Как модерировать

Отдельной панели нет: всё делается в консоли D1 (вкладка **Console**).

Посмотреть свежие отзывы:

```sql
SELECT id, name, substr(body, 1, 80) AS начало,
       datetime(at / 1000, 'unixepoch') AS когда
FROM reviews WHERE hidden = 0 ORDER BY at DESC LIMIT 50;
```

Спрятать отзыв с сайта, не удаляя:

```sql
UPDATE reviews SET hidden = 1 WHERE id = 'сюда-id';
```

Удалить совсем:

```sql
DELETE FROM reviews WHERE id = 'сюда-id';
```

Посмотреть, где читателей цепляет сильнее всего:

```sql
SELECT chapter, pid, emoji, COUNT(*) AS сколько
FROM reactions GROUP BY chapter, pid, emoji
ORDER BY сколько DESC LIMIT 40;
```

## Что внутри

| Путь | Что делает |
|---|---|
| `GET /reactions?chapter=3` | все реакции главы: `{абзац: {эмодзи: сколько}}` |
| `POST /react` | поставить, сменить или снять свою реакцию |
| `GET /reviews` | отзывы, свежие сверху, без спрятанных |
| `POST /reviews` | новый отзыв |

Защита, которая уже работает:

- отзыв короче ста символов, без имени или со ссылкой не принимается;
- скрытое поле-ловушка: бот его заполняет, человек не видит, такой отзыв
  молча отбрасывается;
- не больше двух отзывов и шестидесяти реакций с одного адреса за раз;
- реакция хранится как одна строка на читателя и абзац, поэтому накрутить
  счётчик повторными нажатиями нельзя;
- принимаются только восемь известных эмодзи, прислать произвольный нельзя.

Запросы принимаются только с адресов из списка `ALLOWED`.
